# Lower Your Rates — Broekgaarden

Data, plotting code, and figures behind the **"Lower Your Rates"** compilation of
compact-object coalescence (COC) merger-rate-density predictions from the
literature. The project gathers published local merger-rate estimates for
binary black holes (BH-BH), neutron-star–black-hole binaries (NS-BH), and
binary neutron stars (NS-NS) across formation channels and population-synthesis
studies, and produces the figures and interactive tables used in the paper.

`lower-your-rates-supplementary_material.pdf` is the supplementary material that
accompanies the paper.

## Folder layout

```
Lower-Your-Rates-Paper-Broekgaarden/
├── data/            # rate catalogs (CSV) + raw extracted data
├── plotting_code/   # scripts & notebook that turn the catalogs into figures
└── figures/         # generated figures (PDF/PNG) and interactive HTML
```

### `data/`

One CSV per **formation channel**, each a catalog of published merger-rate
estimates:

| File | Channel | Rows |
|------|---------|-----:|
| `isolated-binary-evolution.csv` | Isolated binary evolution (the main, largest catalog) | ~4500 |
| `CHE.csv` | Chemically homogeneous evolution | 31 |
| `globular-clusters.csv` | Globular clusters | 93 |
| `nuclear-clusters.csv` | Nuclear star clusters | 108 |
| `young-stellar-clusters.csv` | Young / open stellar clusters | 57 |
| `triples.csv` | Triple/multiple systems | 81 |
| `flybys.csv` | Stellar flybys | 3 |
| `population-III.csv` | Population III stars | 19 |
| `primordial.csv` | Primordial black holes | 6 |
| `observations-GWs.csv`, `observations-kilonovae.csv`, `observations-pulsars.csv`, `observations-sGRBs.csv` | Observational rate constraints (GWs, kilonovae, Galactic pulsars, short GRBs) | — |

Each catalog row is one study/model prediction. Key columns include
`compact_object_type` (`BH-BH` / `NS-BH` / `NS-NS`), `formation_channel`,
`study_key` (machine-readable unique key per DCO type × study), `label`,
bibliographic fields (`first_author`, `year`, `ads_url`, `arxiv_url`), `code`
(population-synthesis code), `rate_Gpc3yr` (the predicted local rate in
Gpc⁻³ yr⁻¹), `submodel`, and physics-assumption columns (`sigma_kick`,
`alpha_CE`, `beta_MT`, `lambda_CE`, `RMP`, `stellar_tracks`, …).

**`isolated-binary-evolution_relationships.csv`** — a derived "relationships"
table for the isolated-binary catalog. Each row is a *single-parameter
variation* within one study: a pair of submodels (`from_submodel` →
`to_submodel`) that differ in exactly one physics assumption
(`parameter_family`, `parameter`), with the corresponding rates
(`from_rate_Gpc3yr`, `to_rate_Gpc3yr`) and a human-readable change
(`from_value` → `to_value`). This drives the interactive merger-rate table.

Subfolders:
- `data/individual_extracted_data/` — per-study raw extractions (digitized
  figure data, downloaded tables) plus the small `add_<study>_data.py` scripts
  that ingest each one.
- `data/interactive_plots/` — standalone interactive HTML rate plots.
- `example_relationships.csv` — a small schema example for the relationships
  format.

### `plotting_code/`

- `Make_figures_COC_rates.ipynb` — main notebook; produces all paper figures
  and the interactive merger-rate table.
- `plot_rates.py` — matplotlib plotting helpers (year-sorted rate plots,
  CDF/violin summaries by parameter family and by population-synthesis code).
- `make_interactive_figures.py` — Plotly versions of the rate-density figures
  with hover details (study name, submodel).
- `merger_rate_table.py` — builds the interactive HTML merger-rate table
  (`make_merger_rate_table`) from `isolated-binary-evolution_relationships.csv`;
  supports filtering by DCO type / parameter family / rate limit, and a
  direction-independent "change factor" column (`×N` reduction, `:N` increase,
  sorted by magnitude).
- `python_utils_adding_rates/` — maintenance utilities: `add_<study>_data.py`
  ingest scripts, `convert_to_tidy_format.py`, `make_relationships_csv.py`
  (regenerates the relationships table — see note below), and
  `update_from_literature*.py` / `fix_<study>_*.py` one-off data fixes.
- `submodels_below_49p4_Gpc3yr.csv` — helper list of submodels below the
  GWTC-5 BH-BH upper limit.

> **Note:** `make_relationships_csv.py` is stale — some taxonomy entries were
> hand-edited directly in `isolated-binary-evolution_relationships.csv` and not
> reflected in the script, so do not blindly full-regenerate the relationships
> CSV from it.

### `figures/`

Generated outputs (regenerated by the notebook / scripts):
- `Rates_*_yearsorted*.{pdf,png}` — local merger rate vs. publication year, per
  DCO type (with optional isolated-binary-only variants).
- `*_rate_CDF_and_violin_by_parameter_family.{pdf,png}` and
  `..._by_population_synthesis_code.{pdf,png}` — distribution summaries.
- `figures/interactive/` — interactive HTML: per-DCO rate plots and
  `merger_rate_table.html` (the interactive relationships table).

## Regenerating outputs

Most figures and the interactive table are produced from
`plotting_code/Make_figures_COC_rates.ipynb`. The interactive merger-rate table
can also be generated directly:

```python
import pandas as pd
from merger_rate_table import make_merger_rate_table   # run from plotting_code/

rels    = pd.read_csv("../data/isolated-binary-evolution_relationships.csv")
studies = pd.read_csv("../data/isolated-binary-evolution.csv")
make_merger_rate_table(
    rels, studies_df=studies,
    output_file="../figures/interactive/merger_rate_table.html",
)
```

Requires `pandas`, `numpy`, `matplotlib`, `plotly`, and (for the table's inline
display) `IPython`.
